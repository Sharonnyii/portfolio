# Sharon Yii — New Media Scenographer

Single-page portfolio. Plain HTML/CSS/JS, no build step.

## Publish with GitHub Pages
1. Create a new repository on GitHub (e.g. `portfolio`).
2. Upload **all** files in this folder (drag them into the repo page → Commit). `index.html` must stay in the repo root next to the images and videos.
3. Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch `main`, folder `/ (root)` → Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Files
- `index.html` — the whole site
- `reel.webm` — **put your original `animo-spiral-stream-900p.webm` here and rename it `reel.webm`** (not included in this zip because of the download size limit)
- `void.webm` — black-hole background (1080p)
- `leak.webm` — light leak behind the Instagram link
- `cf-*.jpg`, `fedsquare-*.jpg` — project images
- `sharonnyii.png`, `sharonnyii-solid.png` — name artwork (chrome image + white silhouette)

Fonts (Google Fonts) and Three.js / Lenis (cdnjs) load from the web, so the page needs an internet connection.
GitHub rejects single files over 100 MB; every file here is well under that.
